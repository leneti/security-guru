# ADR 0003: Calm, photo-free visual direction

- Status: Accepted as starting direction
- Date: 2026-09-28

## Context

The preferred direction is calm and residential. There are no genuine project or team photos; the existing site images are AI generated. The site still needs to address offices and homes equally.

## Decision

Start with a calm, approachable design that does not depend on photography. Use typography, generous spacing, the brand palette, and restrained graphics derived from the logo to establish character. Keep office content equally visible. Do not carry over current AI images.

## Consequences

- Establish a new type scale, spacing system, responsive layouts, and component language during design exploration.
- Use dark green for strong text and orange for prominent actions; check actual color combinations for accessible contrast before implementation.
- If original photography becomes available later, the layout may accommodate it but should work without it.
- Violet is part of the source palette, but its exact role in the new interface remains a design choice.
