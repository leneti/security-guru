# ADR 0010: Use the current Rust based pnpm v12

- Status: Accepted
- Date: 2026-09-29

## Context

The owner explicitly wants the latest pnpm v12 release, whose CLI is written in Rust. On 2026-09-29 the npm `latest` dist-tag resolves to `12.8.1`. This machine has Node `22.20.0`, which satisfies the [pnpm installation guidance](https://pnpm.io/installation/).

## Decision

Pin `pnpm@12.8.1` in the new root `package.json` and use pnpm for the new lockfile and all package operations. Upgrade the pin intentionally when a newer compatible v12 release is verified.

## Consequences

- The installed Corepack `0.34.0` shim tries to load `bin/pnpm.cjs`, which pnpm v12 no longer ships; `corepack pnpm` fails on this machine. `npx --yes pnpm@12.8.1` works and was used to create the fresh lockfile. Fix the machine's package-manager launcher before routine development, or invoke the pinned CLI directly. Do not downgrade to v10 merely to satisfy this Corepack version.
- Package versions for Next.js, React, testing, and OXC are still to be selected for the fresh scaffold.
